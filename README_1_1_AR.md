# ToDo — نسخة Windows للتجربة

## التشغيل
1. فك الضغط كاملاً داخل مجلد جديد؛ خلي ToDo.exe ومجلد _internal وباقي الملفات مجموعين.
2. افتح ToDo.exe. نسخة Windows ما كتحتاجش تثبيت Python.
3. الدخول الأول: Administrateur، الرمز 1234.

## تجربة بمنتوجات جاهزة
افتح TEST_TODO.bat: كيستعمل قاعدة demo/demo.db المنفصلة وكيبان اسم المحل ToDo - DEMO.
فيها 3 منتوجات، جوج بطاقات صور تجريبية، زبون TEST وكيس مفتوحة بـ100 درهم.
- جرب الباركود 990001 لمنتوج Riz TEST؛ أو اختار بطاقة من الصور حسب العائلة.
- F6 لاختيار الزبون؛ SOLDER ثم VALIDER لإتمام البيع.
- Crédit متاح عند اختيار زبون: المبلغ المدخل تسبيق نقدي والباقي دين.
- Gestion > Clients > اختار الزبون > Règlements لتسديد الدين نقداً.
- الصور الملونة مجرد بطاقات اختبار. بيانات التجربة لا تدخل لقاعدة المحل التي يستعملها ToDo.exe مباشرة.

## ما تم التحقق منه
اختبارات الحسابات، البحث والعائلات، الشراء، البيع نقداً وبطاقة وبالدين، التسديدات، المرتجعات، الكيس، وأزرار الواجهة مع إخراج PDF.
التسديد العام يتوزع على أقدم الفواتير. المرتجع يلغي الدين أولاً، ويرجع نقداً فقط ما سبق قبضه.
قبل ترقية قاعدة قديمة تُنشأ نسخة في migration_backups.

## حدود معلنة
هذه نسخة تجريبية وليست نهاية جميع متطلبات المرجع. تسديدات الموردين، الجرد المتكامل، بعض وظائف المرجع، والطباعة على الطابعة والدرج الحقيقيين لم تكتمل تجربتها. PDF العربي ومقاسات التذاكر الحرارية غير متحقق منها بعد.
مبالغ التسديد القديمة غير المرتبطة بكيس لا تُضاف تلقائياً إلى الكيس الحالية.
احتفظ بنسختك القديمة. لنفس بيانات المحل يمكن استعمال ImporterToDo.exe قبل إنشاء قاعدة في النسخة الجديدة.

## التشغيل من المصدر فقط
Python 3.10+ مع tkinter وrequirements.txt، ثم ToDo.pyw. هذه الخطوة لا تخص نسخة Windows الجاهزة.
